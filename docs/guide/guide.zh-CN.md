# EmbodiScope 使用说明

EmbodiScope 用来在训练之前检查、理解、清洗和对比具身智能数据集（LeRobot v2.0 / v2.1 / v3.0，以及 GR00T 风格的 LeRobot 数据）。所有计算都在浏览器本地完成，数据不会被上传。

> 右上角的「中文 / EN」开关会切换整个页面的语言，包括本说明。

## 1. 快速开始

1. **打开数据**：点击右上角「打开本地文件夹」，或把文件夹直接拖进页面。选择单个数据集或包含多个数据集的父目录都可以，平台会自动发现所有 `meta/info.json`。
2. **看概览**：左侧选择数据集，「数据概览」页显示规模、帧率、相机、状态/动作构成、坐标约定和标注精细度。
3. **看片段**：在左侧 episode 列表中点击任意 episode，进入「片段可视化」，按空格播放。
4. **做质量扫描**：在「质量检测」页点击「开始全量扫描」，数千个 episode 通常只需几秒到几十秒。
5. **清洗与导出**：给有问题的 episode 打上「剔除 / 待复查」标记，在侧栏导出 episode 列表，供训练时过滤。

### 推荐浏览器

Chrome 或 Edge（支持文件夹访问 API 与 AV1 解码）。Firefox / Safari 可以通过「选择文件夹」上传对话框使用，但 AV1 视频可能无法播放。

## 2. 数据来源

| 方式 | 适用场景 | 说明 |
|---|---|---|
| 本地文件夹 | 个人电脑上的数据 | 文件按需读取，大文件只读取需要的字节范围 |
| 拖拽 | 快速查看 | 支持拖入文件夹 |
| Hugging Face Hub | 公开 / 私有数据集 | 输入仓库 ID，私有仓库需要 token；只下载实际查看的部分 |
| HTTP URL | 静态服务器上的数据 | 服务器需允许 CORS 与 Range 请求 |
| 数据服务 `serve.mjs` | 数据在远程 GPU 服务器上 | `node scripts/serve.mjs /data --port 8686`，浏览器打开该地址即可自动连接 |

URL 参数：`?hf=lerobot/pusht` 直接打开 Hub 数据集；`?server=http://host:8686` 连接远程数据服务。

## 3. 各页面功能

### 3.1 数据概览

- **规模**：episode 数、帧数、总时长、episode 时长分布。
- **本体与动作空间**：本体类型（单臂 / 双臂 / 人形 / 移动 / 灵巧手 / 人手）、状态与动作的组成（例如 `L·joint(7) + L·gripper(1)`）、动作空间与动作类型（绝对 / 增量 / 速度）。
- **坐标与单位约定**：旋转表示、四元数顺序、参考坐标系、长度与角度单位、夹爪极性、相机模型。「已声明」表示来自 `info.json` 的 `convention` 字段，「推断」表示由平台推断。
- **标注精细度**：任务指令 → 逐 episode 指令 → 子任务分段 → 技能 / 帧级原子标注 → 场景描述，评分 0–5。
- **相机、参考坐标系树、特征列表、附加元数据**（README、info.yaml、标注词表等）。
- 右上角可以导出 Markdown 报告。

### 3.2 片段可视化

- **视频**：多相机同步播放。v3.0 的拼接视频会自动按 episode 偏移定位。
- **投影叠加**（⊕）：当相机有内参，并且外参与末端位姿处于同一参考系时，末端坐标轴或人手骨架会被投影到视频上。**投影落在夹爪 / 手上，说明坐标系、四元数顺序和外参方向都正确。**
- **3D 视图**：红 = X、绿 = Y、蓝 = Z。大坐标轴是参考系，小坐标轴是末端；半透明的"残影坐标轴"显示沿轨迹的姿态变化；黄色锥体是相机视锥。右上角可以切换参考系、竖直轴（Z-up / Y-up）、轨迹、残影、动作目标和相机。
- **Action chunk 预览**：设置预测步数 H 后，3D 视图会从当前帧画出未来 H 步的动作目标轨迹，便于理解 ACT / Diffusion Policy / π0 这类模型的监督信号。
- **URDF 机器人模型**：对于只有关节角的数据集（ALOHA、SO-101、RoboTwin 关节版等），可以加载 URDF 文件，平台用正运动学画出机器人连杆与末端坐标系，并自动按名称匹配关节。
- **时间轴**：元数据子任务（如 AgiBot `action_config`）、帧级标签（如 RoboCoIN 的子任务 / 运动方向，会自动用词表解码）、夹爪开合、AI / 人工标注、启发式分段。点击或拖动定位，双击片段跳到起点。
- **标注编辑**：在时间轴下方可以新建或编辑子任务分段：设为当前帧、拆分、删除、修改文字。修改后的结果可以在 AI 标注页导出。
- **信号曲线**：实线为观测，虚线为与之配对的动作。点击曲线定位，标签可以隐藏或显示某组曲线。曲线只在滚动到可见区域时才渲染。
- **帧数值**：当前帧所有信号的数值，旋转会同时换算成 xyzw 四元数。

### 3.3 语义结构 / 坐标系

平台会把每个特征拆成若干"信号片段"，并给出角色、侧别、旋转表示、参考系、单位、夹爪极性和动作类型，同时列出推断依据和置信度。

- **可以直接修改任何单元格**，修改会按数据结构签名保存，下次打开相同结构的数据集时自动应用。
- 带 ⚠ 的旋转表示存在歧义（例如只写了 `rot_x/y/z`）。切换后可以立即在 3D 和投影中验证。
- **逐维统计**：同一信号的所有维度画在同一坐标轴上，显示 min–max 和均值 ± 标准差。红色表示常量维度，z-score 归一化时会除以 0；黄色表示量程极小的维度。
- **EmbodiSpec 导出**：完整的语义解释（JSON），可以用来驱动训练端的数据转换。
- **AI 格式分析**：让大模型解释每个信号的含义，并一键应用它的建议。

### 3.4 质量检测

| 检查项 | 含义 | 为什么重要 |
|---|---|---|
| 时间戳非单调 / 丢帧 / 采样不均 | 时间步异常 | 视频与动作对不齐，速度估计出错 |
| frame_index 不连续、帧数与元数据不符 | 结构问题 | 索引错位 |
| NaN / Inf | 数值异常 | 训练会直接崩溃 |
| 首尾静止段、几乎静止的 episode | 无有效动作的帧 | 策略学会"等待"，或学到无效样本 |
| 动作尖峰 / 跳变 | 单步变化异常大 | 遥操作抖动、IK 翻转、录制中断 |
| 四元数未归一化 / 符号翻转 | q 与 −q 混用 | 回归目标不连续 |
| 欧拉角 ±π 跳变 | 角度回绕 | 归一化与回归出错 |
| 动作与当前状态相同 | action[t] == state[t] | 动作不含未来信息，需要平移 |
| 动作领先状态 k 帧 | 控制延迟 | 影响 action chunk 对齐 |
| 运动带宽 | 90% 运动能量所在频率 | 判断能否时间降采样、控制频率选择 |
| 视频编码 / 帧数 / fps | 视频文件问题 | 无法解码，或视频与数据长度不一致 |

- 问题卡片下方的 episode 编号可以点击跳转。
- 逐 episode 指标表可以排序，点击行打开对应 episode。
- **扫描结果会缓存在浏览器中**，再次打开同一数据集时会自动恢复；需要时可以点「重新扫描」。
- 工作空间图显示所有 episode 的末端位置采样（XY / XZ / YZ 三个投影）。

### 3.5 数据集对比

- 并排对比所有数据集卡片字段，**存在差异的单元格会高亮**。
- 自动生成「混合训练前需要统一的事项」，例如帧率、四元数顺序、旋转表示、动作空间、夹爪极性、单位、参考系和相机数量。
- 叠加显示时长分布和末端工作空间。
- 可以导出 Markdown / CSV / JSON。

### 3.6 AI 标注

1. **配置模型服务**：选择预设（OpenAI、通义千问、DeepSeek、智谱、Kimi、硅基流动、OpenRouter、Anthropic、Gemini、Ollama、vLLM），填入 API Key，然后点「测试连接」。默认 Key 只保存在当前会话中，勾选「在本机记住 Key」后才会长期保存。
2. **格式分析**：只发送结构信息（字段名、维度、数值范围、首帧数值、元数据），不发送图像和完整数据。
3. **子任务分解与 caption**：选择相机、帧数、粒度（子任务 / 原子动作）和范围。平台会均匀抽帧，附带夹爪开合、运动停顿等本体线索，并发请求多模态模型。结果会出现在时间轴上，可以手动编辑。
4. **导出**：`subtasks.jsonl`，或带 `action_config` 的 LeRobot v2.1 `episodes.jsonl`（AgiBot 风格，可以直接写回数据集）。

> 如果遇到 CORS 报错，说明该服务商不允许浏览器直接调用。可以改用本地代理、Ollama 或 vLLM。没有 Key 时，可以用 `npm run mock-llm` 启动模拟服务来体验整个流程。

## 4. Episode 标记与数据清洗

- 在片段可视化页顶部可以把当前 episode 标为 **保留 ✓ / 剔除 ✗ / 待复查 ?**，并添加备注。快捷键：`G` 保留、`B` 剔除、`R` 待复查。
- 左侧 episode 列表可以按标记筛选，也可以只显示质量扫描中出现问题的 episode。
- 在侧栏「导出列表」可以导出：
  - `episodes_keep.json` / `episodes_exclude.json`：episode 编号列表；
  - `episode_flags.json`：包含标记、备注和问题的完整记录。
- 质量检测页的问题卡片支持「全部标为待复查」。

## 5. 链接定位与分享

地址栏会实时记录当前数据集、页面、episode 和帧号（例如 `#ds=…&tab=episode&ep=12&f=340`）。刷新页面后会回到同一位置；使用数据服务或 Hugging Face 打开时，可以把链接直接发给同事。

## 6. 快捷键

| 按键 | 功能 |

## 7. 常见问题

- **视频黑屏或提示无法解码**：浏览器不支持该编码（例如 MPEG-4 Part 2 / FMP4，部分系统上的 HEVC）。请转码为 AV1 或 H.264。数据与 3D 视图不受影响。
- **双击 HTML 打开后无法读取文件夹**：请使用 Chrome / Edge；如果浏览器禁止 `file://` 访问文件夹，可以改用 `serve.bat` / `serve.sh` 或在线版。
- **3D 视图提示"该参考系下没有位姿"**：在右上角切换参考系，或在语义结构页把对应信号设为末端位姿。只有关节角的数据集可以加载 URDF。
- **投影没有落在夹爪上**：依次检查四元数顺序（xyzw / wxyz）、外参方向（camera→robot 还是 robot→camera）和相机光学约定（OpenCV / OpenGL）。都可以在语义结构页修改。
- **数据集很大，加载慢**：通过 Hugging Face 或数据服务打开时只读取需要的部分；质量扫描也可以先运行一部分。
- **CORS 报错（HTTP / Hub）**：服务器需要返回 `Access-Control-Allow-Origin` 并支持 Range 请求。`serve.mjs` 已默认配置。

## 8. 支持的格式

- LeRobot v2.0 / v2.1（逐 episode 文件）和 v3.0（多 episode 拼接文件）。
- GR00T 风格 LeRobot：读取 `meta/modality.json`，按其中定义的分组拆分 state / action。
- parquet 中内嵌的图像与 16 位深度 PNG（例如 RoboMIND、physical-intelligence/libero）。
- 附加标注：`annotations/*.jsonl` 词表、episode 级 `action_config` / `subtasks`、`info.yaml`、README。
- 暂不支持（规划中）：原始 HDF5（robomimic / LIBERO / RoboTwin 原始版）、RLDS / TFDS、Zarr。
